View GitHub Live Demo

About the Project

Guardi is a safety companion application developed as a class project. The application allows a user to create a walking trip and provides monitoring throughout their journey.

The goal was to create an application that could provide an additional layer of safety for people travelling alone.

Key Features

Trip Planning

Users can create a trip with a starting point, destination and optional stops.

Live Location

The application tracks the user's location throughout the active trip.

Safety Monitoring

A monitoring system can follow the user's journey and respond to potential issues.

Automatic Alerts

The system can detect situations requiring additional attention.
